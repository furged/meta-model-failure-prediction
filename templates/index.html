SYSTEM OVERVIEW

WHAT THIS SYSTEM DOES

Modern AI models can sound extremely confident even when they are wrong. This project attempts to detect those hidden failures before users trust the prediction.

Instead of relying on one model alone, the system compares three different sentiment systems: DistilBERT, VADER, and TF-IDF Logistic Regression.

Their predictions, confidence levels, disagreement patterns, and uncertainty signals are analyzed by a second AI model trained specifically to detect transformer instability.

WHY THIS MATTERS

Tiny text changes like:

amazing → reliable
amazingg → warning triggered
amazinnggg → transformer failure

Humans still understand the meaning instantly. But the transformer becomes unstable. The meta-model detects that instability before complete prediction collapse.

PROJECT DOSSIER

PROJECT SUMMARY

This project is an AI reliability system designed to predict when transformer-based sentiment models may fail under noisy or adversarial inputs.

Instead of only classifying sentiment, the system focuses on a harder problem: determining whether the AI itself should be trusted.

SCALE + MODELS

  • Trained on 5,000 adversarially perturbed SST-2 samples.
  • Uses DistilBERT, VADER, and TF-IDF Logistic Regression together.
  • Meta-model analyzes entropy, confidence, and cross-model disagreement.
  • Detects transformer instability using a second-stage classifier.

KEY RESULTS

  • Transformer failure recall improved to 0.87 after adversarial robustness testing.
  • Entropy emerged as the strongest predictor of transformer failure.
  • Small spelling corruptions significantly increased failure probability.
  • Cross-model disagreement became a major reliability signal.
  • System successfully identified high-confidence transformer failures.
